# Руководство и правила разработки для ИИ-агентов (AGENTS.md)

> [!IMPORTANT]
> Данный документ обязателен к соблюдению всеми субагентами и разработчиками, вносящими изменения в репозиторий **Antigravity Pro (`AntygravityPro`)**.

---

## 1. Структура проекта и правила модификации

- **Веб-интерфейс и плавающие модули:**
  - Все новые модули и интерфейсные доработки размещаются исключительно в `assets/web/generated/patches/`.
  - Стилизация окон и компонентов строго следует дизайн-системе Quiet Luxury (`quiet_luxury.css`).
  - **Запрет на относительные пути в `index.html`:** В `<head>` всегда должен присутствовать `<base href="/" />`, а все скрипты и стили должны ссылаться на абсолютные корневые пути (`/generated/patches/...`), чтобы не ломать маршрутизацию при перезагрузке страниц в SPA (`/c/<id>`).

- **Нативный слой (Android Smali):**
  - Классы системных мостов находятся в `smali/com/agy/bridge/`.
  - При расширении API в `DesktopNativeBridge.smali` всегда аннотировать методы через `.annotation runtime Landroid/webkit/JavascriptInterface;`.
  - Использовать динамические свойства Android (`android.os.Build.MODEL`, `VERSION.RELEASE`), не хардкодить имена конкретных устройств или учетных записей.

- **Работа с большими бинарными файлами (>100 МБ):**
  - Файл ядра `liblanguage_server.so` (173 МБ) хранится в Git в сжатом виде `assets/runtime/bin/liblanguage_server.so.gz` (50 МБ).
  - Никогда не коммитить несжатый файл `liblanguage_server.so` — он заблокирует push в GitHub проверкой лимита 100 МБ.

## 2. Правила компонентов интерфейса

1. **Файловый менеджер (`module_explorer.js`):**
   - Меню трех точек (`.ag-file-more-btn`) и кнопка `+ В чат` (`.ag-file-chat-btn`) обязаны содержать `onpointerdown = (e) => e.stopPropagation()`, чтобы клик по кнопкам не вызывал случайный Drag & Drop.
   - Движок перетаскивания активируется только при удержании от 150 мс или сдвиге курсора/пальца более 8 px.
   - Во время перетаскивания окно проводника обязательно должно получать класс `.ag-dragging-translucent` для обеспечения видимости чата.

2. **Оконный менеджер (`window_manager.js`):**
   - Все операции перемещения окон выполняются только через `requestAnimationFrame` с аппаратным ускорением `transform: translate3d(...)`.
   - Запрещено использовать библиотеки с тяжелым оверхедом. Чистый нативный JS.

3. **Вставка путей в чат (`drag_drop_bus.js`):**
   - Редактор чата построен на Lexical. Вставка пути обязана схлопывать выделение в конец диапазона (`range.collapse(false)`) и вызывать как `document.execCommand('insertText')`, так и `InputEvent('beforeinput')` для синхронизации виртуального дерева Lexical.
